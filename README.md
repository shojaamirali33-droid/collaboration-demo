# Collaboration Demo Project

This project is used to practice Git and GitHub collaboration workflows.

## Feature description

This project demonstrates a simple collaborative workflow. Contributors can propose changes through Issues, implement them in separate branches, submit Pull Requests, participate in Code Review, and verify changes through CI.

## How to contribute

1. Open an Issue describing the proposed change.
2. Create a separate branch for the Issue.
3. Make the required changes.
4. Commit and push the changes.
5. Open a Pull Request.
6. Participate in Code Review.
7. Address requested changes.
8. Merge the approved Pull Request.

## CI

The project uses GitHub Actions to run a simple CI check whenever changes are pushed or a Pull Request is created.
